# 第三方组件

- Rockstar Games / Take-Two Interactive：官方游戏美术与商标；素材来源见 assets/sources.json。此作品是本地个人壁纸实现，非官方应用。视差使用的背景补全与透明人物层经 imagegen 编辑生成，见 docs/图层素材说明.md。
- Anton：Vernon Adams 等，SIL Open Font License 1.1，完整文本见 Anton-OFL.txt。
- PySide6 Essentials / Shiboken6 / Qt 6.12：Qt Company 及贡献者，发行元数据列明 LGPL-3.0-only OR GPL-2.0-only OR GPL-3.0-only。应用使用 QtCore、QtGui、QtWidgets 与由打包工具解析的动态运行库，未修改这些库。许可文本见 LGPL-3.0.txt 和 GPL-3.0.txt。
- CPython 3.11：Python Software Foundation License，见 Python-LICENSE.txt。
- PyInstaller：GPL 加引导程序分发例外，见 PyInstaller-COPYING.txt。

完整应用源码位于仓库 src/，重建入口为根目录 build.ps1。若需替换 PySide6 / Qt 动态库，可修改 pyproject.toml 中的版本、使用 uv lock 更新锁文件后重建，也可将 PyInstaller 的 --onefile 改为 --onedir 生成可直接替换 DLL 的目录布局。
