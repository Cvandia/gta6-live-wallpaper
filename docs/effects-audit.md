# EXE / Web 效果一致性审查

审查日期：2026-10-16；目标版本：v1.3.0。

- EXE 的 VI 已采用 Web 的三层渐变光晕、9 秒往返渐变、6.8 秒呼吸和 16 个固定位置的错峰星芒；移除了原有移动扫线。
- Web 已采用 EXE 的 64 个粒子种子、颜色、尺寸、正弦横移、向上漂浮、亮核和短拖尾。
- 两端读取同一份 `assets/effects-spec.json`。Web 用本地脚本读取参数，支持离线加载。
- 审查修复：低于 1 的缓存 DPR 导致 EXE 光晕缩小错位；现在显式指定逻辑绘制尺寸，并新增回归测试。
- 审查修复：Canvas 内部加色不足以复现 EXE 对背景的加色；Web 粒子层使用 `mix-blend-mode: plus-lighter`。

## 验证结果

- 31 项 Python 测试通过。
- 3,239 项 Web 断言通过，覆盖实际绘图调用、参数同步、暂停、恢复、隐藏、开关和内存边界。
- 4,608 组 Python / JavaScript 粒子状态对照通过，包含位置、透明度和拖尾。
- 在真实浏览器中冻结到第 2 秒，与 EXE 同相位预览对照，三层 VI 光效计算结果一致：

| 图层 | 透明度 | 渐变位置 |
| --- | ---: | ---: |
| aura | 0.748750 | 83.976916% |
| halo | 0.809500 | 10.141527% |
| edge | 0.819063 | 61.365275% |

保留原有帧率设置。EXE 光效位图缓存继续限制在 22 MiB 内；Web 粒子主画布限制为 3,686,400 像素。Qt 与浏览器的抗锯齿和模糊实现存在细微区别，不宣称逐像素相同。
